DRIVEABILITY - NGC

Symptom:
    U0168-NO SKIM BUS MESSAGE



When Monitored and Set Condition:

        U0168-NO SKIM BUS MESSAGE
        When Monitored:     Ignition on or engine running.
        Set Condition: No J1850 messages received from the Smart Key Immobilizer Module
        (SKIM) for 20 seconds. One Trip Fault. Three good trips to turn off the MIL.



                                         POSSIBLE CAUSES
GOOD TRIP EQUAL TO ZERO
NO RESPONSE FROM SKIM
PCI BUS CIRCUIT OPEN FROM PCM TO SKIM
SKIM/PCM

         With the DRBIIIt, read the DTCs and record the related Freeze Frame data.

                 Yes   → Go To    2

                 No    → Refer to the INTERMITTENT CONDITION Symptom (Diagnos-
                         tic Procedure).
                         Perform SKIS VERIFICATION.

         NOTE: This test will indicate if the bus is operational from the DLC to the

         Was the DRBIIIt able to communicate with the SKIM?
                 Yes   → Go To    3
