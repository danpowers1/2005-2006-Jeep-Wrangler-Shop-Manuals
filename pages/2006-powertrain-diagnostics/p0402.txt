TRANSMISSION - 42RLE

Symptom:
    P1713-RESTRICTED MANUAL VALVE IN T2 RANGE



When Monitored and Set Condition:

        P1713-RESTRICTED MANUAL VALVE IN T2 RANGE
        When Monitored:        Ignition on, engine running with the gear shift selector in a valid
        forward gear.
        Set Condition: This DTC sets whenever Transmission control system detects the manual
        valve is in the T2 range when it should be in OD. This is mainly an informational DTC.
